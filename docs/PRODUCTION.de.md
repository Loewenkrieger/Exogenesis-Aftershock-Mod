# Produktionsübersicht — 0.3.3

Beschleuniger wirken einmal auf Prozessgeschwindigkeit und Strombedarf. Leerlauf, volle Ausgänge/Rückläufe und ausgeschaltete Anlagen ziehen keinen Prozessstrom. Die Energie einer Calamity-Zelle bleibt auch beschleunigt auf 9,6 Millionen begrenzt; zum Laden werden mindestens zwölf Millionen benötigt.

Alle Mengen gelten pro Charge. Flüssigkeiten, Kühlung, Strom und Erzeugung werden zusätzlich in Einheiten pro Sekunde angegeben. Eingänge funktionieren auf allen Seiten. Nur Ausgangsrichtungen drehen mit dem Gebäude.

Kühlmittelrücklauf rechts (80 %); Flüssigkeitsprodukte vorne/links/hinten. Volle Nebenprodukte oder Rückläufe stoppen. Strommangel pausiert. Ein bewusster Chargenabbruch verwirft reservierte Stoffe. Gaspatronen enthalten 100 Einheiten und werden beim Entpacken zurückgegeben.
